## [0.1.0] - 2025-04-05

### Added

- Dashboard with KPI cards showing consumption, costs, and trends
- Meter reading entry form with date and kWh input
- Consumption chart visualization using Recharts
- Analytics page with period filtering (week, month, year)
- History view for browsing past readings
- Cost calculation with configurable tariff rates
- Settings page for tariff configuration
- Dark mode support via next-themes
- Data export/import functionality as JSON
- Responsive sidebar navigation
- Mobile navigation support

### Changed

- Upgraded to Next.js 16.2
- Migrated to Tailwind CSS v4

### Fixed

- Various UI fixes and improvements
